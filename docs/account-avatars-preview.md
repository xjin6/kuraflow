# 账号头像与入口调整（本地预览）

2026-10-21，已随独立待办页面发布，线上版本 `02c3dbe3-7b71-4165-9d4d-b3b26cbc21ae`。详细回执见 `docs/cloud-deployment-status.md`。

## 界面

- 管理端待办菜单使用圆点列表图标，菜单移除员工管理；左下角个人头像及顶部个人头像可进入自己的员工／账号页。门店端也沿用个人入口，平台保留面向客户的员工支持页面。
- 管理端员工页固定本厨房，移除门店下拉选择。厨房负责人可通过门店管理卡片上的人员图标进入指定门店的账号页；左下角个人入口始终返回自己的厨房团队。原有编辑、结算、报价行操作顺序保留。
- 厨房头像与人物头像分开：厨房负责人可从左侧公司头像或团队资料修改厨房头像；本人及有权限的负责人可从人员列表头像进入上传。平台人员列表也支持客户人员头像编辑，平台左下角可修改自己的头像。
- 上传支持 PNG／JPEG／WebP，原图最多 5 MB，进入统一的正方形裁剪、拖动和缩放。应用裁剪后点击保存才提交，取消不上传；压缩后不超过 200 KiB。

## 数据与权限

新增本地迁移 `0010_account_avatars.sql`，以独立 `account_avatars` 和 `organization_avatars` 表保存头像及图片版本。头像更新不改变账号登录版本，不撤销会话，不修改厨房业务修订号，也不覆盖门店照片。删除头像保留独立版本，冲突时保留预览并提示刷新。

- `POST /api/team/avatar`：`{accountId,version,image}`。
- `POST /api/organization/avatar`：`{tenantId,version,image}`。
- `GET /api/account-avatar?account=...&v=...` 与 `GET /api/organization-avatar?tenant=...&v=...`：鉴权读取，不公开缓存。

本人可以修改个人头像；普通管理员不能修改别人或厨房头像；厨房／门店负责人仅可操作原有授权范围，平台须为实际平台负责人。图片元数据随会话、员工列表、客户资料下发，图片字节不混入列表。校验来源、图片类型、体积和独立版本；图片与审计在同一事务保存，失败回滚。
