# 管理端工作流调整 · 本地预览

本次仅更新本地实现，未发布。

- 待办只展示主动录入的记录，移除系统推送、手动标题和来源标签。标题、备注和截止日期共用新增／编辑表单；按截止日期展开、收起；同组内拖动排序，列表模式可跨日期排序。完成记录可恢复，原内容及顺序保留。数据仍按厨房共享，旧 `source: manual` 字段保留兼容。
- 商品与库存表第二列是成本价，以商品基础单位计价。显式保存的成本优先；旧成本表仅在唯一引用、计价单位及规格明确一致、无冲突标记时显示参考原值，不自动换算或覆盖资料。
- 库存编辑增加“无限”选项。独立布尔标记与空值／零分开，原数量不清空；无限模式不扣减公司数量，但有限的门店分配额度仍约束订货。切回数字库存时按当前订单占用及分配额度校验。
- 原采购成本页签改为报价管理。支持多个可命名方案（不限定为示例中的 3 个），直接读取当前商品目录及可售卖单位；每个单位可设置售价与税口径。方案关联门店后持续生效，历史订单价格不回算；原独立报价保留，切回独立报价时恢复使用。为避免误改其他门店，选用方案的门店不接受单店直接改价，需编辑方案或切回独立报价。
- 方案编辑、门店批量关联、成本和待办编辑／排序带版本检查，使用既有 D1 业务事务及幂等命令。门店端仅得到本店有效报价，不返回成本、方案目录、其他门店价格或分组关系。

使用现有商品 JSON 与厨房 core JSON 保存字段，无需新增数据库表。新增字段包括 `costPrice/costVersion`、`stockUnlimited`、`quotePlans`、门店 `quotePlanId/quoteAssignmentVersion`、`manualTaskOrder/manualTaskOrderVersion` 和待办 `version`。原成本资料、独立报价、订单历史、已完成待办均保留。

初版曾提供三套空白方案用于 review；现有方案及关联继续使用本地已保存的用户编辑结果，不重新初始化。界面验收待办以“【预览】”标注，不导入生产环境。

验证包括：39 项业务模型、47 项原有存储／待办／通知回归、4 项新版业务存储检查、145 项前端与 Flow 数据检查。实际浏览器验证了待办新增、编辑、鼠标拖动、完成与恢复，成本列位置，无限选项，方案创建、价格编辑表单、门店选择入口，以及 420×912 手机布局。


## 2026-10-25 控件与主题试稿

- 取消将三套示例误作数量上限的限制；前后端支持继续创建更多方案，保留同名校验、事务及原有容量保护。新增后滚动到当前方案，方案 tabs 使用更清晰的字号和字重，较多时横向滚动。
- 门店报价顶部的门店与方案选择器使用同一站内下拉组件并排显示，选择方案后保存至当前门店；保存失败恢复已保存选择。
- `portal-theme.css` 统一三端侧栏、主按钮、选择线、菜单选中态、日期与焦点颜色。平台灰紫、管理灰蓝、门店灰橙，正文和业务状态保留清楚的中性色与语义色；颜色由与 favicon 共用的端口映射驱动。此轮仅为本地视觉 review，未上线。
- 主题基本文字组合检查：侧栏文字／辅助文字与底色，以及强调文字与白底／选中底色的对比均不低于 4.5:1。此项为对应配色检查，不代替整个站点的无障碍审计。
