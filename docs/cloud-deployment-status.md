## 免费方案的实际限制

当前作为小规模试用版交付，尚未证明可承受正式集中订货的负载。Workers Free 标称 CPU 预算为每请求 10ms。首轮聚合指标无 Worker 错误，CPU 中位数约 5ms、P99 约 47ms；第二轮开启短时实时诊断的 28 次请求也均为 `ok`，其中状态读取约 11–15ms、业务写入约 24–33ms，并发幂等重试最高 54ms。

这些是 CPU 时间，不能与约 0.6–3.8 秒的端到端网络等待混淆。Cloudflare 的短时 CPU 缓冲允许部分请求超出标称值而成功，但不能把缓冲当作持续预算。因此目前的成功检查不代表容量保证；在全面承接门店正式订单前，仍需进一步精简写请求与实测压测。尚未为此升级任何收费方案。

诊断连接已关闭；只保留脱敏后的路径、状态与时间记录 `private-deploy/live-performance.json`。后续不应简单加入 TTL 库存缓存来掩盖问题，以免跨实例显示旧库存。

- 平台密钥仅保存摘要；厨房／门店负责人使用 16 位混合码（AES-GCM 密文及 SHA-256 索引）。普通管理员使用唯一账号名和 scrypt 密码哈希。
- 识别码由服务器生成，D1 以 SHA-256 唯一索引及 AES-GCM 密文保存；仅管理员可读取所属公司的门店码。登录受 IP 限流与 Origin 检查保护，权限固定关联到单一门店。
- 会话 Cookie 使用 Secure、HttpOnly、SameSite=Strict；写操作校验正式 Origin。
- D1 使用修订号 CAS、批量事务及幂等请求保护订单和库存。
- 采购成本、源材料、其他门店价格不会进入门店接口。
- 公共构建不含原始 materials、完整业务种子、源账单、邀请 token 或源码 map。
- 商品上传限制为压缩后 200KB、每家公司 100MB、每日 100 次；图片接口需认证。

## 发布维护

后续代码发布使用项目内 Wrangler CLI 和绑定本目录的 `kuraflow` OAuth profile。发布前核对固定账号和资源绑定，保留完整数据库备份、Time Travel 恢复点及冻结代码／资产；正常部署沿用线上 secret，不轮换凭据。

```sh
npm run build:cloud
./node_modules/.bin/wrangler deploy --profile kuraflow --dry-run --outdir dist-worker/release --metafile dist-worker/release/metafile.json
node private-deploy/prepare-cli-snapshot.mjs
```

冻结目录由 `private-deploy/current-release-path.txt` 记录。核对后使用 `wrangler deploy --profile kuraflow --config <冻结目录>/wrangler.frozen.json --no-bundle --strict` 发布，并保存 CLI 回执。发布后核对最新版本、生产流量、绑定、相关接口和公开资源 SHA-256；浏览器用于页面验收。旧 Safari 控制台脚本仅作历史记录。

`private-deploy/worker-secrets.json` 保存 `STORE_CODE_KEY`，作为原密钥备份；当前发布流程直接保留线上 secret binding。该文件必须保密并保留安全备份，不可丢失或在已有识别码时随机重建，否则管理员不能恢复查看已有码。密文通过公司/门店范围做 AEAD 认证，公共构建不包含密钥。

静态资产上传由 Wrangler 管理，未变更资产自动复用。当前完整发布回执按时间保存于 `private-deploy/releases/`；`private-deploy/production-release.json` 为早期历史回执。

不要重新执行正式 seed：脚本会在已有公司数据时拒绝覆盖。迁移脚本仅用于明确的数据库升级。`private-deploy/seed.sql` 是早期不完整导出，不可用于正式恢复；完整参数化初始数据为 `seed-queries.json`。

`scripts/test-hosted-cloud.mjs` 只在专用临时公司中测试，并在 finally 中清理。`scripts/safari-metrics.mjs` 查询最近一小时聚合性能；`scripts/safari-tail.mjs` 可建立短时诊断连接，完成后执行 `stop`。

所有私有种子、邀请 token 和诊断记录位于 `private-deploy/`，已加入 `.gitignore`，不能作为公开资产发布。初始管理员注册成功后应删除本地一次性邀请文件。
