# 平台客户、门店与账号

已于 2026-10-20 15:26（北京时间）正式发布，版本 `157d3dae-e7d6-4bc0-82b5-4c4017c04d7d`。平台功能在本地 review 后与纳品书页脚修改一起上线，详细回执见 `docs/cloud-deployment-status.md`。

平台客户列表中的客户名称可打开客户详情，分为「门店与账号」「管理端管理员」。页面集中展示已保存门店的图片、地址、联系人、电话、路线、行政区划、门店编号以及账号资料；可包含已删除门店。新资料读取不创建或激活任何负责人身份。

负责人 code 通过既有受保护接口按需查看和复制，不随门店列表批量下发。已删除门店不提供可用的负责人码入口。负责人使用 code 登录，无独立密码。

管理员密码目前只保存 scrypt 校验值，无法恢复或展示原文。平台页面显示账号名、姓名、联系方式、启停状态、密码是否已设置、创建时间和最近登录时间，并提供明确的「重置密码」操作。新密码与确认一致且提交后才执行；不会自动更改任何账号密码。密码不保存在前端状态、浏览器存储、返回结果或日志，成功／关闭／切换弹窗时清空输入。

新接口仅限实际平台负责人：

- `GET /api/platform/customer?tenant=...`：门店资料和两级管理员清单，严格字段投影。
- `GET /api/platform/store-image?tenant=...&store=...`：验证门店及图片均属于该租户，再读取已保存图片；不开放通用平台图片访问。
- `POST /api/platform/staff/password`：显式目标租户、门店、账号、版本和新密码。仅可重置管理员，不能重置平台或负责人身份；原子校验版本，撤销目标会话和邀请，记录无密码内容的审计。账号状态、其他账号与业务记录保持原样。

后端 21 项检查与前端 25 项检查通过，包含原有账号／Flow 表单回归、租户／角色隔离、密码不回显、已删除门店、图片边界、重置冲突、失败回滚和凭据清除。本地实际读取验证了门店／管理端 code 可按需获取且没有轮换，未重置真实密码。桌面和 420×912 CSS 手机预览均已检查。
