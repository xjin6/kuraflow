# 倉流 クラフロ KuraFlow

倉流（クラフロ）は、セントラルキッチンと店舗の仕事をひとつにつなぐ業務プラットフォームです。

キッチンの開設から店舗との取引、商品の管理、注文、配達、請求まで、毎日の業務をひとつの画面で確認できます。必要な情報を見つけやすく整理し、現場の確認と判断をスムーズにします。

## プラットフォーム

キッチンを開設し、契約店舗やスタッフをまとめて管理します。キッチンごとの利用状況を確認し、必要な機能を設定できます。

## 管理端

中央キッチンの業務を管理するための画面です。

- 商品、規格、販売単位、在庫、仕入原価を管理
- 店舗情報、販売価格、価格プランを管理
- 店舗からの注文、配達、配達準備を確認
- 月次の請求と売上を確認
- 手動の予定や確認事項を登録、編集、完了、復元
- 通知と業務上の対応事項を整理
- Flow に自然な言葉で質問し、必要な操作を確認して実行

商品の追加、店舗の登録、在庫や価格の変更など、業務上の操作は内容を確認してから反映できます。過去の注文や請求情報は、その時点の内容を保ったまま確認できます。

## 店舗端

店舗ごとの注文と日々の確認に使う画面です。

- 注文できる商品と単位を確認
- 現在の価格で注文を作成
- 注文の進行状況と配達予定を確認
- 過去の注文と請求を確認
- 店舗のスタッフを管理

店舗には、その店舗で必要な商品と価格だけが表示されます。キッチン内部の原価や他店舗の情報は表示されません。

## Flow

Flow は、管理端で使える業務アシスタントです。商品、在庫、店舗、注文、請求、予定など、現在のキッチンに関する情報を自然な言葉で検索できます。

PDF、表計算ファイル、CSV、テキスト、画像などの資料を読み取り、ページや行を示しながら内容を確認できます。資料の内容は確認のための情報として扱われ、操作の指示にはなりません。

店舗の追加、商品の登録、価格や在庫の更新、資料からの一括確認など、変更を伴う操作は、内容と変更前後を確認カードで表示します。ユーザーが最後に確認した操作だけが保存され、取り消した操作や確認前の操作は保存されません。

## 倉流が大切にすること

キッチンと店舗が同じ情報を見ながら、それぞれの仕事に集中できること。日々の変更を記録し、過去の注文や請求を正確に振り返れること。倉流は、現場で必要な情報を必要な人に届け、業務を無理なく続けられる環境を目指します。
